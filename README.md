# 家庭菜園ノート v2 + AI診断対応

## GitHub Pages
このフォルダの6ファイルをGitHub Pagesのリポジトリ直下へアップロードしてください。

## 実装
1. 天気API（Open-Meteo）から天気・降水・気温・ET₀を取得し、水やりを提案
2. 区画ごとの作付け履歴から、直近の同科を避ける次作候補を提案
3. 写真診断UI。AIエンドポイントを設定すると画像AIへ送信して肥料提案を受け取れる

## AI診断
APIキーをブラウザへ置かないため、Cloudflare Workerなどのバックエンドを使います。
`ai-worker/` のWorkerをデプロイした後、アプリの「写真から診断」でWorker URLを入力してください。

AI診断は補助情報です。写真だけで栄養欠乏や病害を断定せず、肥料製品のラベルを優先します。
